# NiAD-Large: Dataset for Night-Time Accident Classification

## Overview

This repository contains **NiAD-Large**, a dataset developed for **night-time accident classification**. The dataset is designed to support research in night-time accident detection, anomaly detection, and intelligent transportation systems.

NiAD-Large contains **13,227 annotated frames** representing diverse night-time traffic and accident scenarios.

## Annotations

The dataset provides **frame-level annotations** for binary classification:

- **Normal** – Frames representing normal traffic conditions without a collision.
- **Anomalous** – Frames representing night-time accident/collision events.

## Dataset Details

| Category | Number of Images |
|----------|-----------------:|
| Normal | 8,667 |
| Anomalous | 4,560 |
| **Total** | **13,227** |

## Dataset Access

To ensure responsible use of the dataset, **NiAD-Large is not publicly downloadable directly from this GitHub repository**.

Researchers who wish to use NiAD-Large are required to submit a **Dataset Access Request Form** and agree to the **NiAD-Large Dataset Usage Agreement**.

### How to Request Access

1. Complete the **[NiAD-Large Dataset Access Request Form](YOUR_GOOGLE_FORM_LINK)**.
2. Provide the required researcher and institutional information.
3. Read and accept the **NiAD-Large Dataset Usage Agreement**.
4. Submit the form for review.
5. After the request is reviewed and approved, the dataset access link and instructions will be provided to the registered email address.

> **Note:** Submission of the form does not guarantee access to the dataset. Each request will be reviewed before access is granted.

## Dataset Usage Agreement

By requesting access to NiAD-Large, researchers agree to the following conditions:

- The dataset will be used primarily for **academic and research purposes**.
- The dataset, or any part of it, will **not be redistributed, resold, or shared** with unauthorized individuals or organizations.
- The dataset will not be uploaded to any publicly accessible platform or repository.
- The dataset will not be used for unauthorized commercial purposes.
- The dataset will be used only for the purpose specified in the access request.
- Any research publication, presentation, or other scholarly work using NiAD-Large will appropriately **acknowledge and cite the dataset and its associated publication**.
- Researchers will not attempt to identify individuals appearing in the source data or use the dataset for unauthorized identification or surveillance purposes.
- Access may be revoked if the terms of the agreement are violated.
